# Rock Paper Scissors

This project is part of the Foundations course from **The Odin Project**. In this project, I built a console-based implementation of the classic Rock Paper Scissors game using JavaScript.

By completing this project, I demonstrated an understanding of JavaScript fundamentals, including functions, variables, conditional statements, user input, random value generation, scope, and basic program flow. I also strengthened my ability to break down a problem into smaller components, implement game logic, and organize code into reusable functions.

This project marked my experience building a complete JavaScript application from scratch and provided a solid foundation for developing more complex interactive applications in future projects.
